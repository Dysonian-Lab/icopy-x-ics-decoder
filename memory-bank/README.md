# ICS Decoder Project Memory Bank

This directory tracks the progress, decisions, and research for the ICS Decoder project for the iCopy-X RFID device.

## Directory Structure

- `research/` - Background research, datasheets, and protocol specs
- `decisions/` - Key technical decisions and rationale
- `progress/` - Step-by-step implementation progress logs

## Usage

Each step of the project is documented here. If a crash or context loss occurs, this memory bank allows recovery.
