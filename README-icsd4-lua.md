# iCS D4 Lua Serial Bridge

Portable Lua script for programmatic access to the iCS D4 diagnostic sniffer serial command set. Runs in CLI, Phosphor GUI, and iCopy-X environments.

## Features
- All iCS D4 commands exposed as Lua functions
- Structured parsing into tables (frames, cards, brute results)
- High-level helpers: auto_brute_and_match using inkjet markings
- Dynamic config loading (icsd4.lua.cfg)
- CLI, interactive REPL, JSON output
